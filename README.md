# ERP Contabilidad Pro

Sistema de contabilidad multi-usuario para empresas chilenas.

## 🚀 Features

- ✅ 25 automatizaciones inteligentes
- ✅ Multi-usuario con Supabase
- ✅ Machine Learning para clasificación
- ✅ 95% de automatización
- ✅ Conciliación bancaria automática
- ✅ Predicciones de flujo de caja
- ✅ Reportes ejecutivos automáticos

## 📦 Tech Stack

- React 18 + TypeScript
- Vite
- Supabase (Auth + PostgreSQL)
- TailwindCSS
- jsPDF, recharts, lucide-react

## 🔧 Development

```bash
# Install
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
